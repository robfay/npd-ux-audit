Journey: a Medicare beneficiary searches for a provider and opens the detail page to confirm the provider is legitimate. Unauthenticated on both surfaces.

Primary persona: Barry Beneficiary · Surface: prototype + build · Status: Action needed · Date: 2026-10-03

Headline findings

  1. Avatars: present in the prototype (56x56 with alt text on every result card), absent in the shipped build (none on any result card, none on the detail page). This is the biggest J1 gap and ties to tickets 356 and 359.
  2. Attestation: the shipped build renders attestation as a gray pill; standard NPD-PILL-002 says attestation is an avatar overlay treatment, not a pill.
  3. Status badges: the shipped build uses a multi-color badge system (purple, red, blue, amber); pill standard v1.2 is binary green-check / gray-x only.
  4. Name casing: the shipped build shows ALL-CAPS names with inconsistent order; the prototype uses title case. The content standard favors title case and one name order.
